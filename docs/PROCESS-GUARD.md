# Process guard

Overnight work was lost because it never left the worktree. This guard does not commit and it does not install a hook.

Before ending a session, run:

```sh
sh scripts/guard-uncommitted.sh
```

Exit 0 means `git status --porcelain` is empty. Exit 1 prints the dirty paths. Commit on `fix/eng-90` (or the branch you were asked to use) and push that branch. Do not deploy from this check.

The card publish path is unchanged: 3 straights and one 3-leg parlay, 3:00 and 10:00 ET capture, 10:00 ET card. This script does not touch prices, grading, or schedules.
