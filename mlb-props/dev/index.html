How Picks Are Made — 10-Step Checklist
Every pitcher on the daily slate is evaluated through a strict 10-step checklist before any pick is made. The system fetches real strikeout prop lines from The Odds API (Hard Rock Bet exclusively), pulls ESPN data for confirmed starters and venues, then sends the full slate to Claude with the checklist system prompt. Here is the process:

1. Injury & availability check — Claude web-searches for late scratches, pitch count limits, bullpen games, or injury report changes.
2. Opening line vs current line — Compare the open K line to the current line to detect early sharp movement.
3. Reverse Line Movement (RLM) check — If the line moves opposite to where the public money is flowing, that signals sharp action.
4. Last 5 starts ATS — This is the heaviest-weighted factor. If a pitcher has gone Over in 4-5 of their last 5 starts, that's a Tier A signal.
5. Opponent K vulnerability — Opponent's strikeout rate vs LHP/RHP. Top-10 K% teams are premium targets.
6. Pitch mix & arsenal — Is the pitcher trending toward more whiff pitches (slider, sweeper, changeup)?
7. Park & environment — Strikeout-specific park factors (e.g. Petco 105, Coors 90) adjust expectations. Weather and altitude matter.
8. Game script probability — Blowout risk from the game total line. High totals suggest more pitching changes, limiting K upside.
9. Sharp signal confirmation — Need 2+ of: RLM, last 5 ATS, opponent K% top-10, projection 3%+ edge, situational edge, pitch mix trending up.
10. Commit or Pass — Only pitchers meeting tier thresholds get a pick. PASS is a valid and expected outcome.
Current Architecture Summary
The K Props engine uses a Claude-driven analysis architecture where all raw data is pre-fetched and structured, then Claude performs the full 10-step evaluation for every pitcher. JavaScript fetches: (1) today's MLB events from The Odds API, (2) pitcher strikeout prop lines per event (Hard Rock Bet only), (3) game-level ML + totals for game script context, and (4) ESPN scoreboard data for confirmed starters and venues. All data is formatted into a structured context string and sent to Claude Sonnet with web search enabled (15 searches) for real-time injury/news verification. Claude returns structured JSON with up to 5 picks per day, sorted by tier.
Tier System
Tier A (2-3 units): Last 5 starts 4-5 Over, opponent K% top-10 vs handedness, RLM or 5%+ projection edge, line NOT moved 2+ from open.
Tier B (1-2 units): Last 5 starts 3-5 Over, opponent K% above average, 1+ sharp signal, line within 1K of open.
Tier C (0.5-1 unit): Matchup angle only, marginal 2-3% projection edge.
Pass: Last 5 shows 2 or fewer Over, opponent is top-10 contact team, no signals, or line already moved 2+.
Data Pipeline
The Odds API (events): All MLB events for today with commence times and team names.
The Odds API (K props): Per-event pitcher_strikeouts market from Hard Rock Bet (hardrockbet, hardrockbet_oh). Best over/under odds extracted per pitcher.
The Odds API (game odds): Full-game h2h + totals for game script context (blowout risk, total line).
ESPN Scoreboard: Confirmed starters (name, ID), venue for park factor lookup.
Park Factors: 17 venue-specific K-factors (90-105 range). Higher = more Ks.
Claude Sonnet + Web Search: Full analysis role — runs 10-step checklist for every pitcher, web-searches for injuries, lineup changes, and historical K data. Uses career/historical data when current season sample is insufficient.
