WeBetAI model math

How the Omega model prices a bet, straight from the live code, plus an audit of the Friday, October 16, 2026 Daily Edge card. This page only reports. It does not change any pick, price, or schedule.

1. Verdict: is the on-page math correct?

Mostly yes on arithmetic, no on model honesty. Every price, stake, to-win, grade, parlay and record number on the Daily Edge Picks view (/dashboard?view=omega, which loads /daily-omega) recomputes from the live API and live code. Of 24 checked figures, 17 are correct, 3 are correct only after display rounding, 2 are wrong (a $1 parlay to-win mismatch and a "0%" accuracy shown before any game is decided), and 2 cannot be checked from public data (the Pinnacle fair price and CLV). Three problems matter more than the arithmetic. First, the live model ignores the Pinnacle market anchor (config.js:376-378). Second, the headline record mixes legacy versions. Third, the methodology text on the page describes an older model.

Audited 10:20 PM ET, Oct 16, 2026 against git HEAD d183fbc, published Netlify deploy 6ad2609e011f910a79645529 (published 1:37 PM ET). The card was generated at 1:05 PM ET. Model version v12.4.0-webetai-pure.

2. Audit findings, ranked

  1. Market anchor is off in live code. netlify/functions/lib/omega-vnext/config.js:376-378, where marketAnchorOn() returns false and the OMEGA_MARKET_ANCHOR env flag is ignored (commit 6bf85f5, Oct 15 1:27 PM ET). Published edge is now the raw sport-model probability minus the vigged bet-price implied probability (pure_model.js:157-160). The Pinnacle no-vig price is not used for edge, EV or grade. This is the same setup the Oct 15 audit found inflating edges.
  2. Headline KPIs mix model versions. In daily-omega/index.html:2438-2455, ROI 14.6%, record 292-252, 53.7% and +$12,211 are cumulative since Mar 19, 2026, across every model version. The live Omega model since Sep 22 is 30-28 (51.7%), ROI −1.0%, −$109 (omegaOnly in the same API response). A scope line discloses this, but the big numbers are the legacy blend.
  3. The methodology text is stale. daily-omega/index.html:2678-2688 ("13 sports", "edge vs consensus line … since 6am", "EV via Kelly criterion", Kalshi/Polymarket calibration, "Top 3 by EV") does not describe the live code. Live EV is p×decimal−1, stakes are flat by grade, and ranking uses quality score.
  4. Tulane ML is a sub-floor fill labeled "floor". Edge is 1.52%, under the 2.0% A- line, and EV is 4.9%. The summary says "2 floor straights", but topUps shows Tulane came from the reserve as a short-card fill (card_topup.js, config.js:387-399).
  5. Parlay to-win is off by $1 between surfaces. The API has toWinDollars 334 (from rounded decimal 5.45). The page bet slip and parlay card show +$335 (exact 75×4.4535=334.01, rounded up). Exact rule-based value: $335.
  6. Printed edge/EV use the rounded win rate. This is by design (select.js:474-510, commit dfc20fe). Penguins prints 4.7% / 8.0% while unrounded gives 4.8% / 8.1%. Tulane prints 1.6% / 5.0% while unrounded gives 1.5% / 4.9%. Grades use the unrounded edge, so no grade changes.
  7. Today row shows "0%" accuracy with no decided games. daily-omega/index.html:2519 falls back to '0', while historical rows use "--".
  8. Parlay legs in the API carry p_model: null. This is cosmetic: combined probability still uses each leg's cover probability.

6. The model in plain English

Each sport engine (NFL, college football, MLB, NHL, with NBA off in preseason) projects a margin and a total from team ratings and adjustments, then turns them into a win or cover probability. The live code compares that probability straight to the sportsbook price. Edge is how far the model's probability sits above the price's implied probability, and EV is the expected return per dollar. A bet must show at least 2% EV, sit between −250 and +250, be pregame at a major book, and not be fighting a sharp line move. The best qualifiers by quality score get letter grades. A+ needs 5% edge, A needs 3.5%, and A- needs 2%. Stakes are flat: 1.5u, 1u, 0.75u, or 0.5u, with $150 per unit. When fewer than 3 picks qualify, the card fills with 0.5u leans. When the card has at least two picks, they are combined into a parlay.

What's missing: the sharp market. Pinnacle's no-vig price is captured and used for closing-line grading, but it does not move today's probability. Elite models treat that price as the baseline and bet only where they can show they beat it. Live results so far match a model without a real edge yet: 30-28, ROI −1.0%, and average CLV of +0.4¢ with 47% of bets beating the close.
